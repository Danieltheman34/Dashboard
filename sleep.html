  1. Your Apple Watch saves sleep to Apple Health on your iPhone. A Shortcut sends it here every morning. Set it up once in the Shortcuts app.
  2. Tap + to make a new shortcut, name it Send Sleep, and add Find Health Samples. Set Type to Sleep Analysis, add the filter Start Date is in the last 2 days, and sort by Start Date.
  3. Add Repeat with Each (it uses the Health Samples). Inside the repeat, add a Text action and build:
    Start Date|End Date|Value
    using the Repeat Item variable each time (tap it to pick Start Date, End Date and Value). Tap the Start Date and End Date variables and set Date Format → ISO 8601 with Include ISO 8601 Time on. Keep the | characters between them.
  4. After End Repeat, add Combine Text: combine Repeat Results with New Lines.
  5. Add Get Contents of URL with this URL:
    —
    Tap ▸ to expand it: Method POST, Request Body JSON. Add a Text field token with this value:
    —
    Then add a Text field samples set to the Combined Text variable.
  6. Add Show Result, then run the shortcut once. Allow Health access when asked. It should say Synced … sleep samples.
  7. To run it daily: in the Automation tab, tap + → Time of Day → 10:00 AM, Daily → Run Immediately, and choose Send Sleep. You can delete the Show Result action once it works.
Nights from Apple Health and nights you log by hand both show up here. If both exist for the same night, your manual entry wins.
